# CajaSimple
El punto de venta pensado para tu abarrotes, carnicería o tienda de barrio. Vende, controla tu inventario y sabe exactamente cómo va tu negocio — todo desde una sola pantalla, sin depender de internet.

# CajaSimple — Guía rápida de uso

*Imprime esta hoja y déjala junto a la caja. Cubre lo esencial para vender el primer día — no es el manual completo.*

## Abrir el turno
1. Inicia sesión con tu usuario y contraseña.
2. Si no hay caja abierta, te pide el **fondo inicial** (el efectivo con el que empiezas). Captúralo y listo.

## Vender
1. Escanea el código de barras, o escribe el nombre/código en el buscador — te van saliendo sugerencias mientras escribes (busca por cualquier palabra del nombre, no solo el inicio).
2. Selecciona el producto de la lista (clic o flechas + Enter), o si escaneaste con pistola, se agrega directo.
3. **Si el producto se vende por peso**: se abre la báscula. Pon el producto y espera a que la lectura esté estable (o teclea el peso si tu báscula es manual), y confirma.
4. Repite para cada producto. Si vendes 2 del mismo, se suman solas en la misma línea (no hace falta escanear rarísimo).
5. Presiona **F12** o el botón "Finalizar venta", elige el método de pago, y listo — se imprime o pregunta si quieres imprimir el ticket.

## Corregir un error sin perder toda la venta
- **Ctrl+Z**: quita el último artículo que agregaste.
- **Menú Venta → "Editar venta actual..."**: te deja quitar cualquier línea o cambiar su cantidad, no solo la última.
- **Menú Venta → "Cancelar venta actual"**: borra TODA la venta en curso (úsalo solo si de verdad quieres empezar de cero).

## Si un cliente se va a ir y regresa después
- **Menú Venta → "Suspender venta actual"**: guarda lo que llevas capturado sin cobrarlo, y te deja atender al siguiente cliente.
- **Menú Venta → "Recuperar venta suspendida"**: retoma esa venta cuando el cliente regrese.

## Si el producto no está dado de alta
Cuando el buscador no encuentra nada, te pregunta si quieres darlo de alta ahí mismo, sin salir de la pantalla de venta.

## Devoluciones
**Menú Venta → "Historial de ventas"** → selecciona la venta → **"Devolución parcial"**. Solo se regresa lo que marques, no toda la venta.

## Cerrar el turno
**Menú Caja** → captura el efectivo que contaste físicamente → el sistema te dice si cuadra o si hay diferencia (sobrante/faltante). Se genera un respaldo automático al cerrar.

## Atajos de teclado
| Tecla | Qué hace |
|---|---|
| F12 | Finalizar venta |
| Ctrl+Z | Quitar el último artículo agregado |
| Enter (con sugerencias visibles) | Seleccionar el producto resaltado |
| Enter (sin sugerencias) | Buscar por código exacto |

## Si algo truena
El sistema guarda el detalle del error automáticamente en un archivo — no se pierde. Si pasa, avísale a quien administra el sistema con la fecha y hora exacta en que ocurrió.
